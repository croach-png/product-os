# Recurring meeting context

One file per person you meet regularly. The COS and Manager agents read these before each 1:1 to prepare focused, context-aware briefs.

`/setup-agent` populates this directory automatically from your calendar and meeting notes. You can also create files manually.

## Format

Each file is named `{person-name}.md` and follows the structure shown in `example-person.md`. Keep them living documents — update after each meeting.
