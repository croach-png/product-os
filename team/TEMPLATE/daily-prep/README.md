# Daily prep

Daily brief outputs from the COS agent (via `/daily-prep` or the automated daily script) are saved here as `YYYY-MM-DD.md`.

Keep the last 14 days; let older files prune naturally — the agent reads recent ones for cross-day continuity.

## What a daily brief contains

- **Today's Focus** — 3-5 priorities pulled from todo list, calendar, and current priorities
- **Day plan** — meeting-by-meeting schedule with prep links
- **Meeting prep** — per-meeting brief with attendees, standing topics, carry-forward items
- **Watch list** — items aging without progress, calendar density warnings, stakeholder gaps
