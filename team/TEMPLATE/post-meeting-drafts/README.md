# Post-meeting drafts

After processing a meeting, the COS agent saves a copy-paste-ready summary message here as `{meeting-slug}-{date}.md`. You can paste it directly into messaging tools to share actions with attendees.

Each draft contains:
- Decisions made
- Actions with owners and deadlines
- Open questions
- Carry-forward items for the next meeting

Drafts older than 30 days can be deleted — the actions themselves live on in the todo list and decision log.
