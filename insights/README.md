# Insights

Market analysis, qualitative research, and competitor intelligence.

## Suggested structure

```
insights/
├── qual/           — Qualitative research (interviews, reviews, CX analysis)
├── quant/          — Quantitative analysis (funnel data, cohort studies)
├── market/         — Market trends and competitor research
│   └── competitors/ — Individual competitor profiles and weekly digests
└── summaries/      — Consolidated insight summaries
```

Use `/investigate` to run structured investigations that combine quant and qual evidence.
Use `/competitor-monitor` to generate competitor news digests.
Use `/customer-reviews` to summarise customer feedback from review platforms.
