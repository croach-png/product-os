# Opportunity summary table

**Objective:** Improve X metric by doing Y (eg. Increase activation rate by reducing onboarding friction)

**Example:**

| **Opportunity** | **Sub opportunity** | **Hypothesis** | **Insights** | **Impact (on key metric)** | **Confidence** |
| --- | --- | --- | --- | --- | --- |
| Reduce time to first value to under 5 minutes | Streamline setup flow | If users can complete setup faster we will increase activation rate because users who reach value quickly are more likely to convert | - Average time to first value is 8 minutes. - 72% of users (8/11) from interviews said they would complete setup if they could see value sooner - Users complain about unnecessary steps - 15% of trials are abandoned during setup | M | H |
|  | Guided onboarding assistant | If users have an interactive setup assistant then they would complete onboarding faster and with fewer support tickets. | - Users are frustrated by unclear onboarding steps - Interactive guides reduce support tickets - Interviews evidenced 83% (9/11) of users preferred guided setup | H | M |
|  | Instant checkout — no negotiating | If the purchase was confirmed instantly then we save processing time and reduce abandonment. | - Users want purchase certainty and instant confirmation | H | H |
| Users discover features relevant to their use case | Personalised feature recommendations | If users could discover features tailored to their role and use case they would activate faster and use more of the product | - Users have specific workflows that map to different feature sets
|  | Show personalised value by calculating ROI | If users could see projected ROI for their use case they would upgrade faster and adopt more features | - Users are manually calculating whether the tool is worth the cost without seeing projected value | M | M |
