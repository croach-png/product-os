# PM Training Course: From Discovery to Launch

A hands-on training course that teaches the PM process through a single running scenario. Designed for new PMs or anyone wanting to practise the end-to-end workflow.

---

## The scenario

You're a PM on the Onboarding squad at a B2B SaaS company. 78% of free trial users drop off during onboarding — the biggest drop is at the "invite teammates" step. Your job is to investigate, design solutions, run an experiment, and analyse results.

See `scenario-brief.md` for full context.

## Modules

| # | Module | Command | What you'll produce |
|---|--------|---------|-------------------|
| 1 | Discovery & Prioritisation | `/learn-1-discovery` | Discovery plan, opportunity summary |
| 2 | Solution Prototyping & Validation | `/learn-2-solution` | Workshop plan, solution evaluation |
| 3 | Experiment Design & Prioritisation | `/learn-3-experiment` | Experiment doc, ROTI calculation |
| 4 | Design Best Practice | `/learn-4-design` | Design review, psych audit, assumption map |
| 5 | Build & Launch | `/learn-5-build-launch` | Launch plan, rollout checklist |
| 6 | Analyse & Learn | `/learn-6-analyse` | Results analysis, stakeholder comms, decision |

## Supporting data

Each file provides fabricated but realistic data for the exercises:

- `scenario-brief.md` — role, team, business context, the problem
- `analytics-data.md` — funnel metrics, step-by-step completion rates, cohort data
- `research-findings.md` — 8 user interview summaries
- `competitor-snapshot.md` — how competitors handle onboarding
- `experiment-results.md` — A/B test results for Module 6
- `workshop-ideas.md` — brainstorming output for Module 2

## How to use

1. Start with `/learn-1-discovery`
2. Each module takes 30-60 minutes
3. Modules build on each other — do them in order
4. The coach will guide you through exercises and give feedback

*All data in this training course is fabricated for educational purposes.*
