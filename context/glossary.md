## Generic PM & Analytics Terms

| Term | Definition |
|------|-----------|
| **ARPU** | Average Revenue Per User/Unit |
| **MDE** | Minimum Detectable Effect. The smallest change an experiment can reliably detect |
| **ROPE** | Region Of Practical Equivalence. Range around zero where an experiment result is considered practically equivalent to no effect |
| **ROTI** | Return On Time Invested. Expected impact divided by dev days — used for experiment prioritisation |
| **RAG** | Red / Amber / Green status indicator |
| **YoY** | Year on Year comparison |
| **bps** | Basis points. 1bps = 0.01 percentage points |
| **LTV** | Lifetime Value. Total revenue expected from a customer over their lifetime |
| **CAC** | Customer Acquisition Cost |
| **NPS** | Net Promoter Score |
| **DAU/MAU** | Daily/Monthly Active Users |
